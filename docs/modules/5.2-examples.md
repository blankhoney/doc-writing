# 示例使用指导

使用额外示例前完整读取本指导，再读取对应来源记录与完整所选片段。示例不能代替目标项目证据，不批量读取全部类型样本。

#### 5.2.7 Few-shot 示例

**设计假设**：具体示例有助于表达一致，效果待实测；不声称示例比完整规则更有效。

**示例来源要求**：

| 适合 | 不适合 |
|------|--------|
| 一线成品切片（Stripe 一个端点、K8s 一个命令） | 聚合站/营销站内容 |
| 规范标准（Keep a Changelog 一个版本、Nygard ADR 一篇） | 咨询公司 20 页 PRD |
| 脱敏后的团队真实文档 | 未经验证的 AI 生成内容 |

本节示例按当前表达任务选择，不逐项加载。技术设计的两个任务分支是辅助指导，不设新 `type`，不复制变体正文；测试设计与结果细则共用[按需指导](test-evidence-presentation.md)，仅读取触发的完整节。

短文样本展示完整有限任务；长文片段注明章节与省略范围；构造示意只教语法或排版。按关键行为差异取样，15–25 行是取样参考，不限制全文长度，不截断代码或必要条件，不要求填满全部变体。

> **来源状态**：Requests、Backstage、Django 的已核验范围见[来源清单](../../examples/SOURCES.md)，其余材料按清单核验；未核验草稿不作正向 few-shot。示例不作为目标项目事实。

##### 示例 1：同主题备忘与长设计片段

读取[技术设计模板](../../templates/tech-design.md)中的候选扫描器样本：备忘回答单一取舍，长设计片段展开职责、流程和代价。共享动作/图树示意见 5.8，操作与配置示例分别见 [How-to](../../templates/how-to.md) 和 [Reference](../../templates/reference.md)。

##### 示例 2：Changelog（Keep a Changelog 变体，Security 条目）

实际读取 [Changelog 模板](../../templates/changelog.md)中“已核验：Requests 2.31.0 Security 条目”，示例只在模板中维护一份；[来源记录](../../examples/SOURCES.md#requests-2310)保留固定版本、许可与翻译范围。

**结构要点**：版本与日期定位历史更新，Security 条目同时说明受影响范围、触发条件、不受影响的情况和行动顺序。该例不示范全部分类，也不把原文没有的 Breaking 或迁移步骤补出来。

##### 示例 3：Nygard ADR 的理由与决策句（局部）

实际读取 [ADR 模板](../../templates/adr.md)中“已核验局部：Backstage ADR003”，不再维护另一份未核验的 JWT 成品示例；[来源记录](../../examples/SOURCES.md#backstage-adr003)保留固定版本、许可与删节范围。

**结构要点**：用具体理由支撑决策，并保留例外。原文没有 Accepted 或日期，片段也不包含完整后果；不补造这些字段，不把局部样本宣称为完整 Nygard ADR 合格成品。实际任务仍执行状态、背景、决策和后果的全部适用要求。
