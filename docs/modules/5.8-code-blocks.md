# 代码块规范

输出代码、配置、命令或文件树代码块前完整读取；新代码或改编代码还需读取代码规范。

#### 5.8.5 代码块使用规范

- 代码块用于展示实际代码片段、命令行示例、配置文件示例、事实卡片格式等结构化模板
- 必须标注语言类型（```python / ```yaml / ```json / ```markdown）
- 实际代码核对来源；构造示意标明只教语法或排版
- 按理解需要拆分，不截断语法或必要条件；注释符合语言语法
- 伪代码与可执行代码分开标明；保留相关错误、取消、退出与清理语义，写清省略范围。代码级设计遵循[本次代码规范](../../templates/tech-design/code-conventions.md)
