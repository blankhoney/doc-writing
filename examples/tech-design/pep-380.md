## 形式语义

本节使用 Python 3 语法。

1. 语句

   ```python
   RESULT = yield from EXPR
   ```

   在语义上等价于

   ```python
   _i = iter(EXPR)
   try:
       _y = next(_i)
   except StopIteration as _e:
       _r = _e.value
   else:
       while 1:
           try:
               _s = yield _y
           except GeneratorExit as _e:
               try:
                   _m = _i.close
               except AttributeError:
                   pass
               else:
                   _m()
               raise _e
           except BaseException as _e:
               _x = sys.exc_info()
               try:
                   _m = _i.throw
               except AttributeError:
                   raise _e
               else:
                   try:
                       _y = _m(*_x)
                   except StopIteration as _e:
                       _r = _e.value
                       break
           else:
               try:
                   if _s is None:
                       _y = next(_i)
                   else:
                       _y = _i.send(_s)
               except StopIteration as _e:
                   _r = _e.value
                   break
   RESULT = _r
   ```

2. 在生成器中，语句

   ```python
   return value
   ```

   在语义上等价于

   ```python
   raise StopIteration(value)
   ```

   但与当前一样，该异常不能被正在返回的那个生成器内部的 `except` 子句捕获。

3. `StopIteration` 异常的行为如同如下定义：

   ```python
   class StopIteration(Exception):

       def __init__(self, *args):
           if len(args) > 0:
               self.value = args[0]
           else:
               self.value = None
           Exception.__init__(self, *args)
   ```
