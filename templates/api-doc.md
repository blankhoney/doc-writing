# API 文档
> 面向调用方的接口契约：鉴权、端点、参数、响应、错误码，让调用方不读源码即可正确集成。

> **示例使用范围**：本模板通过变体结构、锚定节、模块与类型验证标准使用，不附样本正文。见[来源说明](../examples/SOURCES.md)。

## 变体选择

```
接口数量和读者场景？
  ├─ 1-3 个端点，内部快速对接          → 快速调用
  ├─ 完整服务 API，团队间集成          → 端点参考（默认）
  ├─ 公开 API / 资源模型复杂           → 资源模型
  └─ 有 OpenAPI spec 生成需求          → 资源模型 + spec 同构
```

## 变体 A: 快速调用

最轻量。适合内部 1-3 个端点的快速对接场景，一页说完。

### 锚定节

| 锚定节 | 锚问 | 排版 |
|--------|------|------|
| 鉴权 | 调用方如何获取凭证、在请求中怎么传？ | 定义列表 |
| 端点 | 路径、方法、必填参数、成功/失败响应的格式？ | 契约表 |
| 错误码 | 遇到错误时调用方应该做什么？ | 契约表 |

### 可插模块

| 模块名 | 锚问 | 排版 | 格式规范 | 有效性检验 |
|--------|------|------|---------|-----------|
| 速率限制 | 调用方的配额是多少、超限后怎么处理？ | 定义列表 | 列出限额数字 + 响应头字段 + 429 后的退避策略 | 有具体数字和退避公式才有效；"请勿频繁调用"无效 |
| cURL 示例 | 调用方复制粘贴即可跑通？ | 代码块 | 可执行的完整 cURL 命令，含鉴权头、请求体、期望响应 | 命令可直接运行（替换 token 后）才有效；伪代码无效 |

## 变体 B: 端点参考（默认）

完整服务 API 文档。按资源分组，每个端点独立成节。

### 锚定节

| 锚定节 | 锚问 | 排版 |
|--------|------|------|
| 概述 | 这个 API 做什么、基础 URL 是什么、版本策略是什么？ | 倒金字塔 |
| 鉴权 | 支持哪些鉴权方式、每种怎么用、权限模型是什么？ | 定义列表 |
| 端点列表 | 有哪些资源、每个资源支持哪些操作？ | 索引 + 深链 |
| 端点详情（每个端点） | 路径、方法、参数、请求体、响应体、示例？ | 契约表 + 代码块 |
| 错误码 | 全局错误格式是什么、每个错误调用方应该做什么？ | 契约表 |

### 可插模块

| 模块名 | 锚问 | 排版 | 格式规范 | 有效性检验 |
|--------|------|------|---------|-----------|
| 分页 | 列表端点怎么翻页、游标还是 offset？ | 定义列表 | 说明分页参数（cursor/limit 或 page/per_page）+ 响应中的分页字段 + 示例请求 | 有参数名、默认值、最大值才有效；"支持分页"无效 |
| 速率限制 | 配额多少、限流响应头是什么、超限怎么退避？ | 定义列表 | 列出具体限额 + 响应头字段名（X-RateLimit-*）+ 429 后退避策略 | 有具体数字才有效 |
| 版本迁移 | 从旧版本迁移需要改什么？ | 差异对照 | Before/After 代码对照 + breaking changes 列表 | 每条变更有具体的代码改动才有效；"请参考新文档"无效 |
| Webhook | 事件通知的 payload 格式和验签方式？ | 契约表 + 代码块 | 列出事件类型 + payload schema + 签名验证方式 + 重试策略 | 有 payload 示例和验签代码才有效 |
| SDK 示例 | 主流语言怎么调？ | 代码块 | 每种语言一个可运行代码片段，含安装、初始化、调用、错误处理 | 代码可运行才有效；伪代码或只有安装命令无效。无 SDK 时删除此模块，链到 Getting Started |

## 变体 C: 资源模型

面向公开 API 或资源关系复杂的场景。按资源（而非端点）组织，每个资源是独立页面。

### 锚定节

| 锚定节 | 锚问 | 排版 |
|--------|------|------|
| API 概览 | 资源总览、关系图、基础 URL、全局约定？ | 索引 + 深链 + Mermaid ER 图 |
| 鉴权与权限 | 鉴权方式、权限模型（OAuth scope / RBAC）？ | 定义列表 |
| 资源定义（每个资源） | 字段 schema、与其他资源的关系？ | 定义列表 / 键卡片 |
| 资源操作（每个资源） | CRUD + 自定义操作、参数、响应？ | 契约表 |
| 全局错误码 | 错误结构、全局错误码、资源特定错误码？ | 契约表 |

### 可插模块

| 模块名 | 锚问 | 排版 | 格式规范 | 有效性检验 |
|--------|------|------|---------|-----------|
| 分页 | 同端点参考变体 | 定义列表 | 同上 | 同上 |
| 速率限制 | 同端点参考变体 | 定义列表 | 同上 | 同上 |
| 筛选与排序 | 列表操作支持哪些筛选/排序字段？ | 契约表 | 列出可筛选字段 + 操作符 + 排序字段 + 默认排序 | 有具体字段名和操作符才有效 |
| 版本迁移 | 同端点参考变体 | 差异对照 | 同上 | 同上 |
| Webhook | 同端点参考变体 | 契约表 + 代码块 | 同上 | 同上 |
| 资源关系图 | 资源之间怎么关联、怎么嵌套访问？ | Mermaid ER 图 + 散文 | ER 图展示关系，散文解释导航路径 | 有图且图与实际 API 路径一致才有效 |

## 类型验证标准（Phase 4 Step 1c）

| 检查项 | 判定标准 |
|--------|---------|
| 参数完整性 | 每个参数有类型、必填标记、约束说明（长度/范围/格式） |
| 错误码可操作 | 每个错误码有"调用方应该做什么"列，不只是错误描述 |
| 路径与代码一致 | 文档中的路径、参数名、字段名与实际代码/OpenAPI spec 一致（5.3.1） |
| 示例可验证 | 请求和响应示例的字段与 schema 定义一致，JSON 格式合法 |
| 鉴权可执行 | 调用方读完鉴权节后能发出第一个合法请求，不需要猜 |
| 必填/选填明确 | 不存在"视情况而定"的参数——要么必填，要么列出可选时的默认行为 |
| 破坏性变更标记 | 废弃端点/字段有下线时间和迁移指引 |
